1기능 카테고리별 상세

각 카드는 실제 소스 디렉터리 단위와 대응합니다. 모든 항목은 코드에서 직접 확인된 것입니다.

캔버스 · 뷰어
  • SVG 자체 렌더링 + 베지어 관계선 외부 다이어그램 라이브러리 없음, 107테이블에서 동작, 관계선은 노드 경계 앵커에서 시작
  • 관계 카디널리티 표기 (IE 까마귀발) N:1(기본) · 1:1 · N:M — 엣지 양끝 마커, 상세 패널에도 표기
  • 미니맵 도메인 색상 축소 뷰 + 현재 뷰포트 표시 + 클릭/드래그 이동
  • 다크/라이트 테마 ☀/🌙 토글, localStorage 유지, 내보내기 이미지에도 테마 색 반영
  • 도메인 그리드 자동 레이아웃 도메인별 5열 배치, 저장 좌표가 있으면 우선
  • 드래그 팬 / 휠 줌 / 줌 버튼 / 전체보기 리셋 rAF transform 조작 — 줌 중 리렌더 없음
  • 노드 클릭 → 관계 강조 인접 테이블 외 자동 dim 처리
  • 상세 패널 도메인 태그, 참조/피참조 관계 목록, 컬럼 PK·UK·FK 배지
  • 테이블명·컬럼명·설명 통합 검색 매칭 외 노드 dim
  • 도메인 필터 범례 클릭으로 특정 도메인만 강조, 도메인별 테이블 수 표시
  • 허브 테이블 강조 표시
실시간 협업
  • WebSocket 실시간 동시편집 저장 버튼 없음 — 적용 즉시 전원 반영 + DB 자동 저장
  • 접속자 presence 아바타 바 — 클릭하면 접속자 전체 목록 드롭다운(본인 "나" 표시), 같은 브라우저 다중 탭은 1명으로 집계
  • 테이블 단위 소프트 락 "○○님이 편집 중" 배지 + 점선 테두리, 접속 끊기면 30초 내 자동 해제
  • 드래그 위치 실시간 중계 50ms 스로틀로 이동 중에도 전원에게 보임, 놓는 순간 확정
  • Undo/Redo 50단계 역연산 기반, 자기 편집만, Ctrl+Z / Ctrl+Shift+Z
  • 자동 재접속 + 전체 재동기화 2초 간격, 서버 heartbeat 15초 ping
편집 · 모델링
  • 편집 모드 토글 보기/편집 분리로 실수 방지
  • 테이블 편집 폼 이름·도메인·설명·컬럼(타입/설명/PK/UK/FK)·참조관계(대상+카디널리티+라벨)
  • 테이블 추가/삭제 삭제 시 관련 관계 함께 정리
  • 도메인 관리 추가·이름·색상·순서 변경, 최대 20개, 삭제 시 소속 테이블 자동 이동
  • 캔버스 스티키 메모 다이어그램 위에 붙이는 공유 메모 — 색상 4종, 드래그 이동, 최대 500자·방당 200개, 실시간 동기화·이력·Undo·이미지 내보내기 포함
  • 노드 배치 저장 드래그 위치가 방 전원에게 동일하게 유지
  • 변경 이력 + 시점 복원 누가 언제 무엇을 바꿨는지 최근 50건(작업명 한글 표기), op마다 전체 스냅샷(방당 1,000개)
임포트 · AI
  • MySQL/MariaDB/PostgreSQL DDL 임포트 텍스트 붙여넣기 또는 .sql 파일 — 주석·백틱·UNSIGNED·COMMENT, PG 스키마 접두어·ALTER ONLY PK·COMMENT ON·serial/다단어 타입·인라인 REFERENCES 파싱
  • 변경 미리보기 → merge/replace 선택 추가/변경/삭제/신규 도메인·관계 요약 후 적용
  • FK 없는 스키마 관계 자동 추론 컬럼명 일치·접미사 매칭·공통 토큰 점수로 부모 테이블 선정
  • 도메인 자동 분류 — 키워드 사전 약 30개 도메인 규칙, 3단계 가중치, FK 이웃 다수결 보정
  • 도메인 자동 분류 — LLM Claude(Haiku) 일괄 분류, 실패 시 사전 방식 자동 폴백
MCP 연동
  • MCP 서버 내장 SSE 트랜스포트 + JSON-RPC 2.0, Claude Code에서 한 줄로 등록
  • 도구 6종 list_rooms · create_room · get_schema · replace_schema · preview_ddl · import_ddl
  • AI 편집의 실시간 반영 MCP 변경도 op 경로를 타므로 접속 중인 브라우저에 즉시 표시
  • 연결 가이드 모달 접속 주소 자동 감지, 등록 명령 자동 생성, 예시 프롬프트 5종
  • Bearer 토큰 인증(선택) ERD_MCP_TOKEN 설정 시 활성화, 미설정 시 사내망 개방
내보내기 · 방 · 운영
  • 내보내기 5계열 SQL(MySQL/MariaDB · PostgreSQL 방언 선택, FK·COMMENT 포함) · DBML(dbdiagram.io 호환) · PNG(2x)/SVG · PDF(인쇄 창 기반) · JSON 백업
  • JSON 불러오기 전체 교체, undo 가능
  • 방 딥링크 + 읽기전용 공유 링크 해시 라우팅 #/room/:id?view=readonly — 게스트는 이름 입력 없이 입장, 편집 UI 숨김, 헤더 🔗 공유 버튼으로 복사
  • 방(Room) 멀티 워크스페이스 최대 20방 × 동시 10명, 데이터·이력·락 완전 분리
  • 방 목록 실시간 현황 5초 폴링, 테이블 수·접속자 수 배지
  • 계정 없는 접속 이름만 입력(1~20자), 이름 해시로 사용자 색상 자동 배정
  • 이름 변경 방 목록에서 변경 — 내가 만든 방들의 생성자 표시명도 함께 갱신(브라우저 식별자 기준)
  • Docker 셀프호스팅 app + db 2컨테이너, Coolify 배포, /api/health 헬스체크

차별화 포인트

주요 상용/오픈소스 ERD 도구 6종과 비교했을 때, MCP 서버 내장, FK 없는 스키마의 관계 자동 추론, LLM 도메인 자동 분류는 ERD Studio에만 있는 기능입니다. 실시간 동시편집 + 편집 잠금 조합은 drawSQL이 월 $59 플랜에 제공하는 수준입니다. 상세 비교는 시장조사 리포트를 참고하세요.
