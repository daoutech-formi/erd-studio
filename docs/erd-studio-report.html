ERD Studio 구축 배경 및 ERDCloud 비교

사내 ERD 협업 도구 자체 구축 경위 · 기능 비교 | 작성일 2026. 08. | 관련 문서: 시장조사 리포트 · 기능 명세서

요약

기존에 사용하던 ERDCloud는 관계도 가독성·DDL 임포트·편집 동선·속도 등 기능/UI 전반에서 실무 요구를 충족하지 못했고, 공동편집 시 누가 무엇을 편집 중인지 보이지 않는 한계가 있었습니다. 이에 도메인 자동 분류·관계 자동 추론·실시간 협업 가시성을 갖춘 ERD Studio를 자체 구축했습니다.

ERDCloud 사용 시 확인된 한계

① 기능·UI 관점 구축의 직접 계기

  • 관계도 가독성 부족 — 테이블이 많아지면 선이 뒤엉켜 특정 테이블 중심의 관계 파악이 어려움
  • DDL 임포트 시 관계 미표시 — FK 제약이 없는 운영 DDL(사내 대부분)은 관계선이 전혀 그려지지 않음
  • 도메인(업무 영역) 분류 부재 — 테이블을 업무 의미 단위로 묶어 보는 기능이 없어 전체 구조 파악이 어려움
  • 편집 동선 불편 — 테이블 추가·컬럼 추가·관계 추가를 각각 따로 등록해야 함
  • 속도 저하 — 화면 확대/축소와 편집 시 반응이 느려 작업 흐름이 끊김

② 공동편집 관점

  • 어떤 테이블이 편집 중인지 표시되지 않음 — 같은 테이블을 동시에 수정하다 서로의 작업을 덮어쓸 위험
  • 누가 편집 중인지 알 수 없음 — 작업 조율이 안 되어 중복·충돌 작업 발생
  • 실시간 접속자 목록 부재 — 지금 누가 함께 보고 있는지 확인 불가
※ 사내 활용(FK 제약 없는 운영 DDL, 대규모 테이블, 다인 동시 편집) 관점에서 확인된 한계 기준

자체 구축의 핵심 계기 Key Drivers

DRIVER 01
도메인 단위로 한눈에 보는 스키마
DDL만 올리면 테이블명·코멘트의 의미를 분석해 회원/주문/결제/발송 등 업무 도메인별로 자동 분류·색상 구분. 150개 테이블도 구조가 한눈에 들어옴.
DRIVER 02
테이블 중심의 관계 탐색
테이블 선택 시 참조(→)·역참조(←) 관계를 강조 표시. FK 제약이 없어도 컬럼명 규칙(user_no → USER 등)으로 관계를 자동 추론해 그려줌.

기능 비교 ERD Studio vs ERDCloud

구분 ERDCloud ERD Studio (자체 구축)
관계 탐색 UX △전체 관계도만 표시 — 선이 얽혀 가독성 저하 ✓테이블 선택 시 참조/역참조 강조 + 검색·도메인 필터
DDL 임포트 → 관계도 ✕FK 제약이 있어야 관계선 표시 ✓FK 없어도 컬럼명 기반 자동 추론 (FK 있으면 우선 사용)
도메인(업무영역) 분류 △수동 색상 지정만 가능 — 의미 기반 자동 분류 없음 ✓테이블명·코멘트 의미 기반 자동 분류 + 도메인 추가/수정/삭제 UI
편집 동선 △테이블 추가 → 컬럼 추가 → 관계 추가를 각각 등록 ✓한 패널에서 테이블·컬럼·관계·도메인 일괄 편집
속도·반응성 △확대/축소·편집 시 지연 체감 ✓경량 캔버스 — 확대/축소·드래그 즉각 반응
공동편집 가시성 ✕편집 중인 테이블·사용자 표시 없음 (덮어쓰기 위험) ✓테이블 단위 편집 락 + 편집 중 사용자 표시 + 실시간 접속자 목록
변경 이력·복원 ✓Undo/Redo · 변경 이력 자동 기록 · 시점 복원 ✓동일 지원 (Undo/Redo · 이력 자동 기록 · 시점 복원)
프로젝트 관리 ✓ERD별 관리 · 팀/멤버 초대 ✓방(Room) 단위 관리 + 동시 접속 정원(10명)·접속 현황 실시간 표시
팀 커뮤니케이션 ✓팀원 간 채팅·실시간 댓글 지원 ✕미지원 — 보완 예정
메모 기능 ✓다이어그램 메모 지원 ✕미지원 — 보완 예정
회원·권한 관리 ✓계정 로그인 · 팀 권한 관리 ✕이름 입력 게스트 방식 — 보완 예정
논리/물리명 전환 ✓논리명 ↔ 물리명 표시 전환 ✕물리명 + 코멘트 병기만 지원 — 보완 예정
AI 연동 ✕없음 ✓Claude 연결(MCP) — 대화 한 문장으로 DDL 임포트·도메인 의미 분류
내보내기 ✓SQL · PNG · Excel · 스냅샷 ✓SQL · DBML · JSON · PNG · SVG
기능 확장 ✕불가 (외부 서비스 의존) ✓사내 요구사항 즉시 반영 (자체 소스 보유)

결론

ERDCloud는 무료로 쓸 수 있는 범용 도구지만, FK 없는 운영 DDL과 다인 동시 편집이라는 사내 조건에서는 관계 파악·편집 효율·협업 가시성 모두 한계가 분명했습니다. ERD Studio는 이 간극을 메우기 위해 구축한 도구로, 도메인 자동 분류와 테이블 중심 관계 탐색이라는 두 가지 핵심 요구를 해결했고, 편집 락과 실시간 접속자·편집 상태 표시로 공동편집의 안정성을 확보했습니다. 나아가 Claude 연동(MCP)으로 대화형 스키마 관리까지 확장해, 단순 대체를 넘어선 사내 표준 ERD 협업 도구로 활용 가능합니다.

도메인 자동 분류 FK 없는 DDL 관계 추론 참조/역참조 강조 탐색 일괄 편집 UI · 빠른 반응성 편집 락 · 실시간 접속자 표시 Claude(MCP) 대화형 관리
