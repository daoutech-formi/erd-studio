캔버스 메모 — 다이어그램 위에 대화를 남기다

2026-08-14

ERD Cloud처럼 캔버스에 스티키 메모를 붙일 수 있게 됐습니다. 리뷰 코멘트·TODO·회의 안건을 테이블 옆에 바로 적어 두면 모든 접속자에게 실시간으로 보입니다. 변경 이력 패널도 한글화·확대로 다듬었습니다.

  • 66c2f15캔버스 스티키 메모메모 op 4종(memo.add/apply/delete/move) — 색상 4종 팔레트, 드래그 이동(50ms 실시간 중계), 최대 500자·방당 200개, 실시간 동기화 · Undo/Redo · 변경 이력 · 시점 복원 · PNG/SVG/PDF 내보내기까지 기존 파이프라인 전체에 편입. 메모 도입 전 JSON/이력 스냅샷과 하위 호환
  • 66c2f15노드 드래그 시 캔버스 팬 겹침 버그 수정테이블·메모를 드래그하면 캔버스도 함께 팬 되던 잠복 버그 — React 합성 이벤트 stopPropagation이 stage의 네이티브 리스너를 막지 못하던 문제를 usePanZoom에서 직접 필터링해 해결
  • 66c2f15변경 이력 패널 개선작업명 한글화(memo.apply → 메모 수정 등), 시각 포맷 단축(12:29:01), 패널 폭 380→620px, 시각·사용자·작업 칸 한 줄 고정
  • 387647c접속자 목록 드롭다운헤더 "N명 접속" 배지 클릭 → 접속 중인 사용자 전체 목록(색상 아바타·이름·본인 "나" 표시), 바깥 클릭으로 닫힘
  • e13dc96사용자 이름 변경방 목록의 ✏ 이름 변경 버튼 — 방 생성 시 브라우저 식별자를 저장해 두고, 이름을 바꾸면 내가 만든 방들의 생성자 표시명도 함께 갱신 (식별자 없는 기존 방은 유지)
  • a5433c4메모–테이블 연결 및 클릭 하이라이트메모 편집 모달에서 테이블을 최대 10개 연결(🔗n 배지 상시 표시) — 조회 모드에서 메모 클릭 시 연결 테이블과 그 사이 관계선만 강조, 테이블 선택 시 연결된 메모는 흐려지지 않음. 테이블 이름 변경/삭제에 links 자동 추종, Undo·이력·기존 5요소 메모 행 하위 호환
  • 03e161d메모 크기 자유 조절편집 모드에서 메모 우하단 모서리 드래그로 폭·높이 조절(90~800px, 내용 높이가 하한) — 새 op memo.resize, 텍스트는 폭에 맞춰 자동 줄바꿈, Undo 시 이전 크기(최초엔 기본 크기)로 복귀, 크기 미지정 기존 메모 행 하위 호환
  • 91703f9캔버스 팬 시 관계 강조 유지 버그 수정테이블 클릭으로 관계를 강조한 상태에서 배경을 드래그(팬)만 해도 강조가 풀리던 문제 — 해제를 mousedown이 아닌 mouseup 시점에 4px 이하 제자리 클릭일 때만 수행하도록 변경, 빈 배경 클릭으로 해제하는 기존 동작은 유지
