# [백로그] 로그인 직후 빈 화면(프로젝트 없음)이 오류처럼 보임

- **발견**: 2026-09-07, SSO 연동 검증 중 (플레이그라운드 실화면)
- **상태**: ✅ 2026-09-07 배치 구현 완료 — 온보딩 히어로·방 빈 상태 카드·프로젝트 생성 모달 적용

## 문제

SSO 로그인 직후 소속 프로젝트가 없는 사용자에게 보이는 첫 화면이 깨진/오류 화면처럼 보인다.

- 내용이 없는 **빈 드롭다운**이 그대로 노출됨 (프로젝트 선택 select)
- 점선 테두리 박스 2개가 연달아 나오며 안내문이 각각 한 줄씩만 떠 있음
  - "아직 속한 프로젝트가 없습니다. 위의 ＋ 프로젝트로 직접 만들거나…"
  - "아직 만들어진 방이 없습니다. 첫 방을 만들어 보세요." ← 프로젝트가 없는데 방 얘기가 나와 어색함
- 전체적으로 "환영/시작" 느낌이 아니라 데이터 로드 실패처럼 읽힘

## 위치

`frontend/src/components/RoomList.tsx`
- ~236행: 프로젝트 select (프로젝트 0개여도 렌더링됨)
- ~257행: `room-empty` 프로젝트 없음 안내
- ~281행: `room-empty` 방 없음 안내 (프로젝트 없음 상태에서도 노출되는 것으로 보임 — 확인 필요)

## 확정된 최소 수정안 (사용자 의견, 2026-09-07)

> "아직 만들어진 방이 없습니다" 박스가 **프로젝트가 없을 때는 노출되지 않도록** 조건 추가.
> 프로젝트 없음 상태에서는 "아직 속한 프로젝트가 없습니다" 안내 하나만 보이면 됨.

## 확정 범위 확대 (사용자 결정, 2026-09-07)

아래 "개선 방향" 4개 항목 **전부 확정 — 배치 수정에 포함**한다.
(최소 수정안을 포함하는 상위 작업이므로, 구현 시 1번 온보딩 화면이 최소 수정안을 대체)

## 개선 방향 (확정)

1. **프로젝트 0개 상태를 별도 온보딩 화면으로 분리** — 빈 드롭다운·방 목록 영역을 숨기고, 중앙 정렬 히어로 카드 하나만:
   - 심볼/일러스트 + "환영합니다, {이름}님" 타이틀
   - 한 줄 설명: "프로젝트를 만들면 팀의 ERD 방을 관리할 수 있어요"
   - Primary CTA: **[+ 첫 프로젝트 만들기]** (기존 addProject 호출)
   - Secondary 안내: "이미 진행 중인 팀이 있다면 프로젝트 관리자에게 **초대 링크**를 요청하세요"
2. **프로젝트는 있는데 방이 0개**인 상태는 지금 문구 유지하되, 점선 박스 대신 카드형 빈 상태 + "＋ 첫 방 만들기" CTA로 방 이름 입력에 포커스.
3. `window.prompt` 기반 프로젝트 생성도 이때 함께 모달로 교체 검토 (트렌디하지 않은 브라우저 기본 prompt).
4. 다크/라이트 테마 모두 확인.
